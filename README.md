# Spotify Clone

https://github.com/user-attachments/assets/fd2a71c7-4b2e-47d5-bf8c-8a38e2f2f613


A modern, responsive web application that replicates the core functionality and design of Spotify. This project was built as a learning exercise to practice front-end development skills and working with modern web technologies.

## Features

- 🎵 Browse and play music from various playlists
- 🎨 Dynamic UI with color themes based on album artwork
- ⏯️ Full media player controls (play, pause, skip, volume)
- 📱 Responsive design that works on desktop and mobile devices
- 🔄 Smooth page transitions between views

## Technologies Used

- **Astro** - The core framework for building the application with partial hydration
- **React** - For interactive components like the music player
- **Svelte** - For specific UI components like the greeting message
- **TypeScript** - For type-safe JavaScript code
- **Tailwind CSS** - For styling the application
- **Zustand** - For state management
- **Radix UI** - For accessible UI components like sliders
- **CLSX** - For conditional class name construction

## Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/spotify-clone.git
   cd spotify-clone
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to [http://localhost:4321](http://localhost:4321)

## Project Structure

```
/src/components   # Reusable UI components
/src/icons        # SVG icons used throughout the application
/src/layouts      # Page layouts
/src/lib         # Utility functions and data
/src/pages       # Application routes
/src/store       # State management
/src/styles      # Global styles
/public         # Static assets like fonts and images
```
